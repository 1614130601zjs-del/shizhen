角色词条库
选择角色卡管理对应的角色词条，或选择「用户外貌」保存自己的固定外貌词；用户外貌不绑定任何角色卡。
只对 NAI V4 / V4.5 / V5 的多角色提示词生效，单人或不拆角色时不起作用。开启后第一个角色在最左、最后一个在最右：两人是左 / 右，三人是左 / 中 / 右。想让谁站左边，就让他在提示词里排在前面。
名字可写 克劳德:1.2、(克劳德:1.2)、1.2::克劳德::、$克劳德$。；也可以写成括号组 (克劳德:1.2, 表情, 服装, source#动作)，括号里的其他词会跟着这个角色走。
世界书里写 {{拾帧角色列表}}，发送给模型前会自动换成这里的角色名单（当前角色卡的词条、未绑定词条、用户外貌），让模型直接写名字、不再自己编外貌。
外貌词里可以写「条件词」：[吐舌|tongue out]tongue piercing，意思是画面提示词里出现 tongue out 才会带上舌钉，没出现就丢掉。适合舌钉、被衣服遮住的纹身这类不常露出的特征，例如 [shirtless|lifted shirt|nude]stomach tattoo。触发词用 | 分隔，英文不区分大小写。
词条名称可用 | 分隔多个别名，例如「克劳德|Cloud」。优先匹配当前角色卡绑定的词条，其次未绑定角色卡的词条，最后才是其他角色卡的词条。
通用词自动注入
默认关闭。发图前由插件自动识别每个角色的性别（看词条里选的性别，没选就看外貌词里的 1girl / 1boy 等）。画面里全是男 → 只把你选好的男通用词在公共区写一遍；全是女同理；男女混合时，才分别写进各自角色的提示词。这样男通用词里放体型 / 骨相，角色词条里就只需要留发型发色和特殊标志。不同角色卡可以各选各的词组，已有的同名 tag 不会重复。
词条头像只在这里给你看，记录“这套词跑出来长什么样”，不会进提示词，也不影响相册头像。
服装库 （场景提示词里出现触发词才会追加，和上面的固定外貌词是分开管理的，增减不用去大段文字里找）

作品库

连接同一台手机上的拾帧素材库 App。只同步拾帧插件自己的设置、素材和图片原始字节，不读取酒馆其他角色卡、聊天记录或世界书。同步前请先打开 App 并保持在前台。
文件备份与迁移
用于手动保存拾帧设置 JSON，或在不同酒馆实例间迁移。文件可能包含 API Key；请勿分享给他人。图片原文件由上面的本地数据库同步单独保存。
图片下载选项
可选择保存为 PNG 或 JPG。PNG 保留原始文件及其元数据；JPG 会重新编码图像，不保留原 PNG 的提示词与生成参数数据块。
放大图小互动（果冻）
在详情页点开放大图后，可以戳一戳、拖一拖、摇一摇图片，松手会 Q 弹地回去。纯装饰，默认关闭。放大图下方的「果冻」小面板可以随时快速切换这些选项，还能涂出「选区」，只让选中的地方动。
悬浮球（小萌物）
屏幕边上放一个可拖动的小萌物，点一下直接打开拾帧；手机摇晃时它会摇头晃脑。默认关闭。

API 配置
这里统一管理拾帧的文本模型连接，取景区中文转 Tag 与小剧场剧情生成共用同一套 API。可跟随酒馆主 API，也可填写独立 API；世界书、预设条目与系统提示词设置仍用于画面 Tag 转换。
读到的条目会作为参考资料交给LLM，帮它贴近正文里角色的外貌、服饰等设定。点下面的按钮可以直接看到当前绑定的世界书都有哪些条目，取消勾选自检清单、彩蛋解析格式这类跟画面无关的条目就行，不用自己跑去世界书里抄名字。
借用预设条目：从酒馆当前预设（聊天补全）里挑几条文字条目，转换时拼在提示词最前面，借用它的文风规范和内容限制；不勾选就不借用。预设里的字数、状态栏、思维链之类的条目别勾，会干扰「只输出一行 tag」。
