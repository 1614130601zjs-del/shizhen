# 拾帧 Android 本地素材库

这是拾帧 Lite 仓库中的独立 Android App 工程，不参与 SillyTavern 扩展加载。

## 当前阶段 0.5.0

- Android WebView 壳，默认使用 App 私有目录保存文件。
- 可通过 Storage Access Framework 选择持久化文件夹。
- 支持导入单个原始文件并列出文件，图片不压缩。
- 保留拾帧 ZIP 备份包的完整性校验与隔离导入能力。
- 支持 Termux 同机酒馆连接检测，默认 `http://127.0.0.1:8000`；只允许本机回环地址。
- 产品边界已明确：本 App 是拾帧插件的外接本地数据库，只同步拾帧插件自身管理的数据，不扫描、备份或修改 SillyTavern 的其他角色卡、聊天记录、世界书。
- 插件数据源以 `extension_settings.shizhen` 为核心，重点覆盖拾帧的图片记录、Vibe 资源池与分组、预设、角色绑定、画师串组合、提示词、作品库及插件自有配置。
- 图片原文件需要从拾帧记录引用的酒馆图片路径读取并复制；对仍为 Data URL 的历史记录则解码保存原始字节。不能只备份设置 JSON。
- 当前尚未实现拾帧专属同步协议、SQLite 索引、增量同步或双向恢复；本版本仅保留本地仓库底座和本机连接检测。

## 构建

使用 Android Studio 打开 android-app/，安装 Android SDK 35 后构建 app。
