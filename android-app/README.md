# 拾帧 Android 本地素材库

这是拾帧 Lite 仓库中的独立 Android App 工程，不参与 SillyTavern 扩展加载。

## 当前阶段 0.2.0

- Android WebView 壳。
- 默认使用 App 私有目录保存文件。
- 可通过系统 Storage Access Framework 选择持久化文件夹。
- 支持导入任意文件到本地素材库并列出文件。
- 原始文件按字节保存，不做图片压缩。
- 禁止 Android 自动备份，避免与用户指定的本地仓库语义混淆。
- 增加 Termux 同机酒馆连接检测，默认地址为 `http://127.0.0.1:8000`，可修改端口。
- 连接检测只允许访问 `127.0.0.1`、`localhost` 或 `::1`，只发送一次 HTTP GET，不读取或修改酒馆数据。
- 连接检测成功仅代表本机端口有 HTTP 响应，不代表 SillyTavern API 已完成认证或配对。

## 构建

使用 Android Studio 打开 android-app/，安装 Android SDK 35 后构建 app。

## 后续阶段

1. 在拾帧 Lite 增加有明确授权边界的酒馆端素材扫描/导出接口。
2. 定义带 manifest、SHA-256 的素材备份包，关联角色卡、世界书、图片、Vibe 和生图记录。
3. Android App 读取备份包并生成可筛选素材库，保留原始文件字节。
4. 增加选择性恢复；恢复前检查文件名冲突和哈希，酒馆删除动作绝不影响本地仓库。
5. 在真实 Termux + SillyTavern 环境验证图片和角色卡恢复接口后，再开放一键清理/恢复流程。

当前版本尚未实现酒馆素材读取/导出、备份包解析、SQLite 索引或一键恢复；不能视为完整同步版本。
